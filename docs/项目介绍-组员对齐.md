# 梦回宋朝 · 项目说明

这份是给项目组同学对齐用的。项目介绍只写小程序里已经有的功能。

## 项目介绍

「梦回宋朝」是一个介绍宋代生活的微信小程序。打开后先是引导页，然后进入首页，可以从首页进入服饰、饮食、住宿、出行。服饰可以看图鉴、历史和课程，也可以选男子或女子，给模特换上衣、下装和外套。饮食分成肉食、素食、面食、点心、饮品，可以查看东坡肉、蟹酿橙、桂花糕等菜品和制作步骤。住宿介绍苏州、晋祠等园林和建筑，可按建筑、园林、室内查看。出行介绍当时的出行方式、交通工具和出行图典。底部还有发现、集市和我的：发现里有「生活在宋朝」「宋韵服饰」「宋朝美食」等话题和帖子；集市可以浏览信笺、茶盏、团扇、香牌等文创并加入购物车；我的里面有头像昵称、订单、创作、收藏、发布、关注、消息、意见反馈、设置和资料修改，并用手机号登录。

## 这次要加的功能

2026-10-16 规划更新：用户已将目标扩展为从首页进入的项目助手，覆盖所有已完成且经过核验的功能，支持搜索后的继续交互。已确定前端经 Java 接入 Python，由 OpenCode harness 使用 DeepSeek V4.1 Flash Free。以下“只加首页搜索”和“不做一问一答”等文字保留为原阶段计划，不再限定当前开发范围；当前需求、数据契约和验收见 [SPEC-002](specs/002-home-intelligent-search.md)，尚未交付的能力不属于现有功能。

只加首页搜索。

用户不用记页面名字，用平时说话的方式搜。结果是小程序里已经有的卡片：一张图、一个标题、一句短说明。点卡片，就进入原来的页面。

举例：

- 搜「东坡肉怎么做」，出来东坡肉那张卡片，点进去就是原来的菜谱。
- 搜「宋代女子出门穿什么，中午吃什么」，同时出来服饰和饮食里已经有的卡片。
- 用户说「想体验一天宋代文人的生活」，就把衣服、吃的、住的、出行里相关的卡片一起找出来，直接点进去。

卡片上的图和字都是小程序里原有的。它不会自己写新文章，也不会自己画新图。小程序里没有的内容，就告诉用户这里没有。
